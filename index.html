Browser runtime

Python is provided by Pyodide in WebAssembly. The runner captures stdout/stderr and has no direct access to your host files. The runner may load pandas on demand, which can take time. External network access is not enabled by this site. Package availability varies; PyArrow and psycopg/PostgreSQL are not assumed to work in-browser.

Run full integrations locally

python -m venv .venv\n# activate the environment, then:\npip install pandas pyarrow requests psycopg[binary]\n# Run your scripts with credentials supplied through environment variables.

Never place database passwords or API secrets in client-side code. Use a least-privilege database role and parameterized SQL.
